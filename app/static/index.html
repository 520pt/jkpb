企业微信智能机器人

                      
                    

                    

                      用于在企业微信群或单聊中直接发送文字命令，例如“菜单、查询今日在岗、查询今日监控、模板”，不需要 artifacts 或 JSON。
                    

                    

                      Bot ID / Secret 获取方式：

                      1）企业微信电脑端 → 工作台 → 智能机器人 → 创建机器人。

                      2）弹出“你需要一个什么样的机器人”时，不要在大输入框里创建，点击左下角“手动创建”。

                      3）进入手动创建页后，把右侧配置页一直滚动到最底部，在保存按钮上方/页面底部找到“API 模式创建 / 切换至 API 模式创建”。

                      4）在 API 配置里选择“使用长连接”，复制 Bot ID；Secret 必须点击“点击获取”后复制真实值，不能留空，也不能填写普通机器人/Webhook 的密钥。

                      5）不要使用普通“群机器人 Webhook”，也不要在 DeepSeek 快速回答/知识库/API/MCP 插件普通机器人页里配置；这些都不能接收群内命令。
                    

                    

                      
                      
                    

                    

                      
                      
                    

                    

                  

                  

                    
                    
                  

                

                

                  

                    

                      
企业微信自建应用

                      
                    

                    

                      启用后，通知发送和命令交互都只走企业微信自建应用；企业微信群机器人和智能机器人不会同时发送/回复。
                    

                    

                      配置步骤：

                      1）企业微信管理后台 → 应用管理 → 自建 → 创建应用，复制企业 ID、AgentId、Secret。

                      2）在应用“接收消息”里设置 URL：/api/wecom-app/callback。

                      3）Token 和 EncodingAESKey 可以在企业微信页面随机生成，再填到这里保存。

                      4）保存本页面配置后，再到企业微信页面点“保存/验证 URL”。群内机器人异常时，优先使用这个自建应用私聊查询。
                    

                    

                      

                        
                        
                        
                        
                        
                      


                      

                        配置测试
                        测试会通过企业微信自建应用发送一条消息。收到后请在自建应用里回复“菜单”，能返回查询菜单就说明回调交互也生效。自定义菜单现在放在“交互菜单”页维护。
